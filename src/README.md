# RoomRadar Application

This folder contains the P3 application implementation.

The approved P2 design uses:
- HTML, CSS and JavaScript for the browser interface
- Python and FastAPI for the backend
- PostgreSQL for persistent storage

Components:
- Room UI
- HTTP API and input validation
- Catalog Service
- Reporting Service
- Status Resolver
- Catalog and Report Repository

Implementation files and shared interfaces will be established before
feature work begins. Do not create a separate application for each member.

The code in /spikes is P2 experimental evidence, not the completed application.
Any departure from the approved design must be documented in P3 section 3.3.
