# P3 Evidence

## Report contributions

Everyone edits the complete shared Google Doc using their own Google account.

When your assigned report sections are ready for review:

1. Comment on your GitHub issue with the section numbers, what you wrote,
   and the completion date.
2. Capture Google Docs version history showing your name, timestamp,
   and the relevant edits. Use additional screenshots if needed.
3. Upload the screenshots to this folder through your own P3 branch.
4. Include them in your pull request.

Name screenshots using:
YYYY-MM-DD-name-section-description.png

Example:
2026-12-02-noor-section-5-traceability.png

Capture another checkpoint after substantial revisions.
A screenshot showing only a name and date is insufficient:
the evidence must also identify the relevant work.

Adam will compile the per-member log and screenshots into Appendix A.

## Reviews

Reviewers record the sections or files checked, the checks performed,
and specific findings in the relevant issue or pull request.
Authors record how they resolved those findings.

## Code and testing evidence

Code, tests, and fixes are committed by their authors.
Test results and build transcripts must come from actual runs.
Each result should identify the command and commit tested.

The clean-clone transcript for Appendix B must be produced by a teammate
who did not write the setup instructions, on another machine.
