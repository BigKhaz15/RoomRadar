# P3 — Final System, Testing, Report, and Demo

P3 builds on the approved P2 baseline, preserved under the `p2` tag.

## Shared report

The team writes and reviews one shared Google Doc using individual Google accounts.
Individual section-only documents are not used.

Document contributions will be supported by a per-member log and named
version-history screenshots in Appendix A.

## Repository work

Each member works from a complete clone of this repository on their own P3 branch.
Members commit and push their own code, tests, and corrections, then open a
pull request linked to their assigned issue.

Reviews must describe checks actually performed and any findings.
Adam coordinates integration and the final report export.

## Final deliverables

- Final report PDF
- Application source code and tests
- Editable diagram sources and exports
- Reproducible test results and clean-clone build evidence
